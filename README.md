# VR_Project

## 1. Project Overview

This project demonstrates a Virtual Reality environment developed using Unity.

### Features
- Interactive 3D environment.
- VR-based navigation and interaction.
- User-friendly interface.
- Real-time interaction with virtual objects.

---

## 2. Software Requirements

- Unity Hub
- Unity 6
- Visual Studio
- Windows 10/11
- Required Unity packages

## 4. How to Open the Project

1. Download or clone this repository.
2. Open Unity Hub.
3. Click Add Project.
4. Select the downloaded VR_Project folder.
5. Open the project using the compatible Unity version.
6. Open the main scene.
7. Press Play to run the application.

---

## 5. How to Run

1. Open the project in Unity.
2. Open the required scene.
3. Check the project settings.
4. Click Play in the Unity Editor.
5. Test the available interactions.
